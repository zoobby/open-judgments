# open-judgments · 公开判断日志

> 事前登记、到期复盘、永不删除。
> 在 AI 能生成一切"看起来像专家观点"的时代，这是一份无法事后补写的个人判断轨迹。

## 这是什么

一个公开的判断日志仓库。每一条判断都在**结果揭晓之前**登记，到期后公开复盘——对错都回填。

它的价值不来自单条判断的对错，而来自三个无法伪造的属性：

1. **你改不了的时间戳** —— git 提交哈希链把"何时说了什么"钉死，五年前的提交记录任何人可核验；
2. **独立的第三方见证** —— GitHub 平台、star/fork、外部归档构成见证网络；
3. **可锚定的稳定身份** —— 全部记录归于同一账号，时间越久越值钱。

## 仓库结构

```
open-judgments/
├── README.md            # 本文件
├── RULES.md             # 判断日志规则（公开承诺，先读这个）
└── judgments/           # 判断记录，按编号+日期命名
    ├── 000-template.md  # 标准模板（九要素）
    └── J-YYYY-NNN.md    # 每条判断一个文件
```

## 核验方法（给读者）

任何人质疑某条记录"是不是事后补写的"，三步核验：

1. 打开对应文件的 **Commits 历史**，查看首次提交时间；
2. 点击该提交的哈希，确认文件内容自首次提交后未经修改；
3. （可选）本地克隆仓库，运行 `git log --follow -- judgments/<文件名>` 独立复核。

## 规则摘要

完整规则见 [RULES.md](./RULES.md)。五条铁律：

- **永不删除**：错判留着附复盘，一次删除五年白干；
- **预先承诺**：写进本仓库的预判到期必复盘，不允许选择性披露；
- **宁缺毋滥**：写不出可证伪形式的判断不登记；
- **合规优先**：不做任何持牌业务性质的推荐（如具体证券标的），敏感信息彻底脱敏；
- **不做单点**：本仓库在本地保留克隆，定期异地备份。
